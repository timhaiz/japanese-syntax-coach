## 5. 隐私披露

App Store Connect 隐私问卷（App 隐私）按以下内容填写：

| 数据类型 | 是否收集 | 是否与身份关联 | 是否用于追踪 | 用途 |
| --- | --- | --- | --- | --- |
| 用户 ID | 是 | 是 | 否 | App 功能 |
| 邮箱地址 | 是 | 是 | 否 | App 功能 |
| 用户内容 | 是 | 是 | 否 | App 功能 |

- 不做追踪（Tracking = No），`NSPrivacyTracking = false`（`docs/ios/PrivacyInfo.xcprivacy` 已声明）。
- 第三方 SDK：Supabase（认证与数据库）、StoreKit（Apple 支付，应用不接触付款信息）、VOICEVOX / AI
  服务仅在用户主动使用相关功能时处理教材内容。
- 隐私清单 `docs/ios/PrivacyInfo.xcprivacy` 与 `NSPrivacyAccessedAPITypes` 目前为空数组，需要在提交前
  用 Apple 隐私清单生成工具复核。

**账号删除（App Store 指南 5.1.1(v)）**

- App 内路径：**账户 → 删除账号**，弹出二次确认对话框，提交精确的 `{ "confirmation": "DELETE" }`。
- 删除会清除云端学习记录、本机待同步答案、缓存进度与待同步购买记录。
- 隐私政策第 5 节已说明可以申请注销账号。**待办**：把隐私政策中的「在『我的』页面申请注销账号」改为
  同时指向 App 内的「账户 → 删除账号」，以免审核员只看到网站路径。

```text

2. 会员功能需要订阅。沙盒购买步骤：
   账户 → 订阅与购买 → 选择「月度会员」或「年度会员」→ 确认购买（系统弹出 Apple 订阅确认框）→ 输入
```
